# Day 17 - Rows, Columns & Wrap in Flutter 🚀

## 📚 Topic

Rows, Columns and Wrap in Flutter

## 🧠 What I Learned

Today I learned about:

- Row
- Column
- Wrap

### Row

Row arranges widgets horizontally.

### Column

Column arranges widgets vertically.

### Wrap

Wrap arranges widgets horizontally and moves widgets to the next line when there is not enough space.
