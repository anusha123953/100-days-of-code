# 🎬 Day 32 – Flutter Movie Discovery App

Welcome to **Day 32 of my 100 Days of Code challenge!**

Today, I built a Movie Discovery App UI using Flutter and Dart. This project helped me practise building interactive interfaces, filtering data, and navigating between screens.

## 🚀 Features

- 🎥 Movie discovery screen
- 🔍 Search movies by title
- 🎭 Filter movies by genre
- ⭐ Display movie ratings
- 📄 Movie details screen
- 🌙 Dark-themed user interface
- 📱 Responsive movie grid

## 🛠️ Tech Stack

- **Flutter** – UI development
- **Dart** – Programming language
- **Material Design** – UI components

## ▶️ How to Run

1. Install Flutter and Dart.
2. Create a Flutter project:

   ```bash
   flutter create movie_app
   ```

3. Replace `lib/main.dart` with the Day 32 source code.
4. Open the project directory:

   ```bash
   cd movie_app
   ```

5. Run the application:

   ```bash
   flutter pub get
   flutter run
   ```

To run in Chrome:

```bash
flutter run -d chrome
```

## 📚 What I Learned

- Creating reusable Flutter widgets
- Using `StatefulWidget` and `setState()`
- Implementing search and genre filtering
- Passing data between screens
- Navigating with `Navigator.push()`
- Designing a dark-themed movie interface

## 📝 Note

This version uses sample movie data and built-in icons. It does not yet connect to the TMDB API or display live movie posters.
