# Dart Lists & Maps 🚀

Today I learned and practiced Lists and Maps in Dart.

## 📚 What I Learned

### Lists

- Creating a List
- Accessing elements using indexes
- Adding elements using `add()`
- Adding multiple elements using `addAll()`
- Sorting using `sort()`
- Checking elements using `contains()`
- Filtering elements using `where()`

### Maps

- Creating a Map
- Understanding Key-Value pairs
- Accessing values using keys
- Getting keys using `keys`
- Getting values using `values`
- Checking keys using `containsKey()`

## 💻 Practice

I created a List of fruits and practiced different List operations.

I also created a Map containing:

- Name
- Age
- Boolean value
- Fruits List

## 🎯 Key Takeaway

Lists store multiple values, while Maps store data using Key-Value pairs.

These are important Dart fundamentals for Flutter development.
