# 🚀 Day 3 – Dart: final & const

## 📚 Topics Learned

Today I learned about the `final` and `const` keywords in Dart.

### 🔹 final

* `final` variables can be assigned only once.
* Once a value is assigned, it cannot be changed.
* The value can be determined at runtime.

### 🔹 const

* `const` is used for compile-time constants.
* The value cannot be changed after declaration.
* It is used when the value is known at compile time.

## 💻 Example

```dart
void main() {
  final String name = "Akshit";
  print(name);

  const double pi = 3.14;
  print(pi);
}
```

## 🧠 Key Takeaway

```text
var   → Can be changed
final → Cannot be changed after assignment
const → Compile-time constant
```
