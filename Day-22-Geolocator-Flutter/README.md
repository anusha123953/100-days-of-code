# Day 22 – Geolocator Package in Flutter 📍

## Overview
On Day 22 of my 100 Days of Code challenge, I explored the Geolocator package in Flutter to retrieve the device's current location.

## Concepts Learned
- Installing the Geolocator package
- Checking location service availability
- Requesting location permissions
- Retrieving latitude and longitude
- Handling location permission errors
- Displaying location data in the Flutter UI

## Technology Used
- Flutter
- Dart
- Geolocator Package

## Output
The application displays the current latitude and longitude when location access is granted.

## What I Learned
I learned how Flutter applications can request location permission and retrieve geographical coordinates using the Geolocator package.
