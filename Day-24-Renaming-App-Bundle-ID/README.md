
# Day 24 - Renaming App Bundle ID

Welcome to Day 24 of my 100 Days of Code challenge!

## 📌 Topic
Renaming App Bundle ID in Flutter.

## 🛠️ Commands Used

```bash
dart pub global activate rename
dart pub global run rename setBundleId --value com.anusha.myapp
```

## 📚 Concepts Learned
- Installing the Flutter Rename package
- Renaming the application Bundle ID
- Using terminal commands in Flutter
- Understanding Android and iOS application identifiers

## 💻 Technologies
- Flutter
- Dart
- VS Code

## 🎯 Learning Outcome
Learned how to use the Rename package to configure a Flutter application's Bundle ID.
