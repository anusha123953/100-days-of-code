# Day 31 - Wallpaper App in Flutter

Built a wallpaper app using Flutter and the Pexels API.

### Features
- Display images in GridView
- Load more images while scrolling
- Fetch images from Pexels API
- Loading indicators and error handling

### Technologies
- Flutter
- Dart
- Pexels API
- HTTP

### Setup
1. Run `flutter pub get`.
2. Add your Pexels API key.
3. Run `flutter run`.
