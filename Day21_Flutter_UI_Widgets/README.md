# 🚀 Day 21 – Flutter UI Widgets

Welcome to **Day 21 of my 100 Days of Code challenge!**

Today, I practiced Flutter UI development by combining multiple widgets into one application.

## 📚 Topics Covered

### 1. Stack
- Places widgets on top of one another.
- Useful for layered UI designs.

### 2. Positioned
- Places widgets at specific positions inside a `Stack`.
- Uses properties such as `top`, `bottom`, `left`, and `right`.

### 3. Neumorphic Design
- Creates a soft UI appearance using light and dark shadows.
- Practiced using `BoxDecoration` and `BoxShadow`.

### 4. VISA Card UI
- Designed a VISA card interface using `Container`, `Stack`, and `Positioned`.
- Added card details, a chip, and shadows.

### 5. TabBar and TabBarView
- Created three tabs:
  - VISA Card
  - Stack
  - Image Picker
- Used `DefaultTabController` for navigation.

### 6. ImagePicker
- Selected an image from the gallery.
- Used `ImagePicker` to select an image.
- Used `Uint8List` and `Image.memory()` to display the selected image.
- Used `setState()` to update the UI.

## 🛠️ Technologies Used
- Flutter
- Dart
- Material Design
- ImagePicker package

## ▶️ How to Run

Install the ImagePicker package:

```bash
flutter pub add image_picker
```

Run the application in Chrome:

```bash
flutter run -d chrome
```

**Note:** Save the Dart code inside a Flutter project's `lib/main.dart` file to run the complete application.

## 🎯 Learning Outcome

Practiced layered layouts, widget positioning, neumorphic shadows, tab navigation, and image selection in a single Flutter application.
