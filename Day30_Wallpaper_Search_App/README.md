
# Day 30 - Wallify Wallpaper Search App

Day 30 of my 100 Days of Code challenge.

## About
Wallify is a Flutter application that fetches wallpapers from the Pexels API. Users can search for photos and preview wallpapers in full-screen mode.

## Features
- Search wallpapers by keyword
- Fetch images using a REST API
- Display photos with GridView.builder
- Full-screen image preview
- Zoomable image preview
- Loading indicators and error handling
- Dark theme UI

## Tech Stack
- Flutter
- Dart
- Pexels API
- HTTP package
- REST API and JSON

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Day30_Wallpaper_Search_App
```

### 2. Install dependencies

```bash
flutter pub add http
flutter pub get
```

### 3. Get your API key

Create a free API key at:
https://www.pexels.com/api/

### 4. Run the app

```bash
flutter run --dart-define=PEXELS_API_KEY=YOUR_PEXELS_API_KEY
```

## Security
Do not commit your real API key to GitHub. For a production app, protect API credentials through a suitable backend.
