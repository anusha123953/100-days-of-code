# Day 24 - Renaming App Bundle ID

## 📌 What I Learned
- Renaming a Flutter app's Bundle ID.
- Using the Flutter Rename package.
- Running commands in the terminal.

## 💻 Technology
- Flutter
- Dart

## 🛠️ Command Used
```bash
dart pub global activate rename
dart pub global run rename setBundleId --value com.anusha.myapp
```
