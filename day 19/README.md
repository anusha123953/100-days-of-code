# Day 19 - Flutter Widgets

## 📅 Day 19 of 100 Days of Code

Today I learned and practiced four important Flutter concepts:

### 1. ListView
- Used to display items in a vertical scrollable list.
- Practiced using `ListTile`.

### 2. GridView
- Used to display items in rows and columns.
- Practiced using `GridView.count()`.

### 3. SnackBar
- Used to display temporary messages at the bottom of the screen.
- Practiced using `ScaffoldMessenger` and `showSnackBar()`.

### 4. Dismissible
- Used to make list items swipeable.
- Practiced deleting an item by swiping it from right to left.
- Used `setState()` to update the UI.
