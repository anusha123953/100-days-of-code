## 📅 Day 11: Python Tuples

Today I learned about **Tuples in Python** and practiced creating tuples, accessing elements, indexing, negative indexing, and slicing.

---

## 📚 Topics Covered

- Creating a Tuple
- Printing a Tuple
- Accessing Tuple elements
- Positive Indexing
- Negative Indexing
- Tuple Slicing
- Different types of Tuple values

---

## 💻 Code Practiced

```python
# Creating a tuple
fruits = ("apple", "banana", "mango", "orange")

# Printing the tuple
print(fruits)

# Accessing elements
print(fruits[0])
print(fruits[1])

# Negative indexing
print(fruits[-1])
print(fruits[-2])

# Tuple slicing
print(fruits[0:3])
print(fruits[1:])

# Tuple with different data types
my_tuple = ("Anusha", 20, 6.62, True)

print(my_tuple)
