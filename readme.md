* `reverse()`

## 💻 Practice

```python
fruits = ["apple", "banana", "mango", "orange"]

print(fruits)

fruits.append("grapes")
print(fruits)

fruits.remove("banana")
print(fruits)

fruits.sort()
print(fruits)

fruits.reverse()
print(fruits)
```
