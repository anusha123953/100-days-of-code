# 🐦 100 Days of Code — Day 12

## Dart For Loop

Today I learned and practiced the **For Loop in Dart**.

## 📚 Topics Covered

- Understanding the `for` loop
- Loop initialization
- Loop condition
- Loop increment
- Printing numbers using a loop
- Printing even numbers
- Repeating statements using a loop

## 💻 Practice Code

```dart
void main() {
  // Print numbers from 1 to 5
  for (int i = 1; i <= 5; i++) {
    print(i);
  }

  // Print even numbers from 2 to 10
  for (int i = 2; i <= 10; i += 2) {
    print(i);
  }

  // Print a message 5 times
  for (int i = 1; i <= 5; i++) {
    print("Learning Dart!");
  }
}
